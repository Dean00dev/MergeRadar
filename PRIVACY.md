# Privacy Policy

_Last updated: 17 August 2026_

MergeRadar is designed to minimize retained customer data.

## Data processed

When installed, MergeRadar may process:

- GitHub account, repository and installation identifiers supplied by GitHub;
- pull request metadata and changed file paths;
- CODEOWNERS content from the pull request base revision;
- GitHub Marketplace purchase/plan events when Marketplace integration is enabled.

## Data retained by v0.1

Pull-request analysis is not persisted by the application by default.

Normalized Marketplace events and the latest normalized entitlement record may be stored in the configured persistent data file.

Operational hosting providers may retain request metadata or logs according to the operator's hosting configuration.

## Source code

MergeRadar v0.1 does not download file contents for changed source files. It reads CODEOWNERS because ownership coverage is part of the product.

## Model providers

MergeRadar v0.1 does not send repository data to an LLM or external model API.

## Deletion

An operator should remove Marketplace/customer entitlement data when it is no longer required and comply with GitHub Marketplace deletion requirements for canceled trials/subscriptions where applicable.
