# Roadmap

## v0.1 — deterministic core

- path-based impact model;
- GitHub Check;
- CODEOWNERS coverage;
- HMAC webhook verification;
- GitHub App installation authentication;
- Marketplace event normalization;
- container deployment;
- explicit product/security boundaries.

## v0.2 — policy packs

- repository `.mergeradar.yml`;
- custom path groups;
- custom review lanes;
- policy validation and schema;
- local CLI preview using the same engine;
- report JSON schema.

## v0.3 — durable operations

- transactional database adapter;
- durable webhook idempotency;
- queue/worker split;
- installation lifecycle cleanup;
- metrics and SLO instrumentation;
- retry policy with dead-letter handling.

## v0.4 — organization view

- multi-repository inventory;
- ownership-gap dashboard;
- historical change-impact trends;
- organization baselines.

## Later, only if evidence supports it

- cross-repository dependency impact;
- reusable policy catalog;
- paid Marketplace plans after eligibility;
- enterprise controls.

No roadmap item is a promise of Marketplace approval, security certification or customer adoption.
